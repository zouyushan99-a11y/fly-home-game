# Area preview images

Five self-generated captures of the actual Urban Wings Canvas scene, not concept images or stock photographs. Generated by `node tools/clarity-scenes.cjs`, then encoded as WebP at quality 90. Models, materials and sky images reuse the game's existing assets and their existing attribution; no new third-party image source was introduced.

| File | Actual scene |
| --- | --- |
| glass.webp | Day city, marked-glass route B, progress 24 |
| light.webp | Night city, illuminated route A, progress 59 |
| green.webp | Ecological corridor C, progress 95 |
| pond.webp | Fishpond/village C, progress 120 |
| wetland.webp | Wetland C, progress 170 |

HUD/navigation labels are hidden for scene captures. Geometry, first-person projection, lighting and textures are the actual renderer. Previews intentionally show a representative view, not a promise that every route has the same appearance. The offline build embeds all five images.
