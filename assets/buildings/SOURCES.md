# Building art sources

All six designs, orthographic sheets and SVG facade/roof textures are original procedural vector artwork created for Fly Home by tools/build-building-designs.py. No third-party architectural images or baked sky photography are used. Window holes are transparent; existing live sky imagery remains a separate rendering layer. Design dimensions are fictional architectural references, not measured buildings. Existing sky sources remain documented in assets/sky/SOURCES.md.

Front and side share floor bands. Runtime repeats the middle elevation band to match actual building height, uses a separate lobby, and maps the roof UV island independently. Setbacks use the existing geometric footprint.
