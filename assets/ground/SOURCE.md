# Ground materials

Original procedural overhead textures generated by `tools/build-ground-art.py`; no third-party imagery or generative model assets. Fixed seed, flat lighting, no baked shadows or road markings. Materials: asphalt, paving, curb, grass. Opposite pixel borders match exactly. Game-world pattern scale: 256 pixels / 24 texels per world unit; cached world map resolution 3 pixels per world unit; marks and intersections are drawn separately into a cached world map. Atlas quadrants: asphalt / paving / curb / grass. Grass-to-paving transitions use feathered world-space edges, not tiled rectangular decals.
