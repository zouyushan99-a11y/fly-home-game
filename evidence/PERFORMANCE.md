# 性能对比与验收记录

Linux / Chromium 154.0.8037.57，headless，`--disable-gpu`，1280×720，DPR 1。不是实体手机。

B 路线、日间进度 28；各 20 帧 RAF 预热、120 帧采样，重复三次。以下固定场景值为三次结果的平均数。另测同轨迹小幅前移与横移（90 帧，丢弃前 10 帧）。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 固定场景平均提交耗时 ms | 1.83 | 2.13 |
| 固定场景平均 RAF FPS | 25.66 | 23.04 |
| 移动场景提交耗时 ms | 1.67 | 4.33 |
| 移动场景 RAF FPS | 27.75 | 22.02 |

新增反射、不同轮廓和植被仍有性能成本。此结果不能宣称性能无回退或保证手机 60 FPS。CPU 提交耗时不是完整帧耗时；FPS 取 RAF 实际间隔，保留两类数据。远景简化、屏外剔除、窄条纹理绘制与小尺寸缓存已实际实现。

浏览器断言：21/21 通过；包含 460 个旋转碰撞检查、完整旅程到达、触屏、键盘、双语、暂停和天空解码。完整原始数据见 results.json；正式网页及离线文件烟测见 smoke.json。
